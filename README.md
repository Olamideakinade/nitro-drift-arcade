**Nitro Drift Arcade v1.3.0** is an upgraded, lightning-fast, arcade-style 2D top-down racing game built entirely from scratch using HTML5 Canvas, Vanilla JavaScript, and CSS3.

## 🚀 What's New in v1.3.0

- **Full Test Suite**: Comprehensive unit tests covering car physics, drift friction, collision checks, and track bounds.
- **Performance Benchmarks**: Real-time render loop latency tracking, FPS stabilization, and stress tests for particle emission.
- **Test Runner Console**: Easily execute diagnostics right from the browser developer console or dedicated test panel.

## 🎮 Controls

- **Steer**: Left / Right Arrow Keys or A / D
- **Accelerate / Reverse**: Up / Down Arrow Keys or W / S
- **Nitro Boost**: Spacebar
- **Pause**: Escape or P

## 🛠️ Development & Testing

To run the test suite:
1. Open `index.html` in a modern web browser.
2. Open the browser DevTools Console.
3. Run `NitroGame.runTests()` to execute unit tests and view performance benchmarks.
