**Nitro Drift Arcade v1.2.0** is an upgraded, lightning-fast, arcade-style 2D top-down racing game built entirely from scratch using HTML5 Canvas, Web Audio API synthesizer, and modern ES6+ JavaScript.

## 🌟 What's New in v1.2.0
- **Cyber Neon Overhaul**: Sleek glassmorphic UI panels with animated neon borders, custom fonts, and crisp HUD elements.
- **Juicy Screen Shake & Particles**: Explosive particle systems for drift sparks, tire smoke, and nitro flames, paired with dynamic camera shake feedback.
- **Enhanced Web Audio Engine**: Procedural sound effects for ultra-satisfying engine roars, screeching drifts, and nitro boosts.
- **Multiple Circuits**: Race across Circuit Noir, Oval Speedway, and Viper Canyon with persistent best lap tracking via LocalStorage.

## 🎮 Controls
- **Steering**: Left / Right Arrow Keys (or A / D)
- **Accelerate**: Up Arrow / W
- **Brake / Reverse**: Down Arrow / S
- **Nitro Boost**: Spacebar
- **Pause**: P or ESC

## 🚀 Getting Started
Clone the repository and open `index.html` in any modern web browser!

```bash
git clone https://github.com/username/nitro-drift-arcade.git
cd nitro-drift-arcade
# Open index.html or serve locally
```
