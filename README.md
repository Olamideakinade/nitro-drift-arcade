**Nitro Drift Arcade v1.1.0** is an upgraded, lightning-fast, arcade-style 2D top-down racing game built entirely from scratch using HTML5 Canvas and Vanilla JavaScript. Experience slick drifting mechanics, advanced particle effects, dynamic synthesized audio, multiple tracks, and persistent leaderboards!

## ✨ Features (v1.1.0)

- **Advanced Physics & Drifting**: Authentic inertia, friction coefficients, and responsive turning mechanics.
- **Web Audio API Synth**: Immersive engine revs, squealing tire drift sounds, nitro explosions, and menu feedback synthesized live.
- **Multiple Unique Tracks**: Race on *Circuit Noir* (Technical), *Oval Speedway* (High Speed), and *Viper Canyon* (Twist & Turn).
- **Nitro Boosts & Power-ups**: Collect nitro refills to sustain blazing speeds and chain massive drift combos.
- **Persistent Best Times**: LocalStorage leaderboards track your absolute fastest laps.
- **Stunning Neon Retro-Futuristic UI**: Glowing aesthetics powered by CSS3 and Google Fonts (Orbitron & Rajdhani).

## 🎮 Controls

| Action | Primary Key | Secondary Key |
| :--- | :--- | :--- |
| Accelerate | `ArrowUp` | `W` |
| Brake / Reverse | `ArrowDown` | `S` |
| Steer Left | `ArrowLeft` | `A` |
| Steer Right | `ArrowRight` | `D` |
| Nitro Boost | `Shift` | `Space` |
| Pause Game | `Escape` | `P` |

## 🚀 Getting Started

Simply clone the repository and open `index.html` in any modern web browser!

```bash
git clone https://github.com/username/nitro-drift-arcade.git
cd nitro-drift-arcade
# Open index.html in your browser
```
